================================================================================
TROUBLESHOOTING
================================================================================

Q: "Tag does not support ISO-DEP"
A: Card is not Rav-Kav compatible. Try a different card or reposition phone.

Q: All probes return SW=6A82
A: This might be an empty card! Check that card is genuine Rav-Kav.

Q: Can't see all output on screen
A: Check logcat: adb logcat | grep RavKavReaderPoC

Q: Installation fails
A: Run: adb uninstall com.unicapitalgroup.ravkavreader
   Then: adb install RavKavCardReader_Enhanced_AUTH-2026-001.apk
