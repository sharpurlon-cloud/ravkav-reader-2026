================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: ADB not recognized
SOLUTION:
  - Install Android SDK Platform Tools
  - Add to PATH: C:\Android\platform-tools (Windows)
  - Restart terminal
  - Verify: $ adb version

PROBLEM: Device not showing in "adb devices"
SOLUTION:
  - Check USB cable (use proper USB 3.0 cable)
  - Enable USB Debugging in Developer Options
  - Try other USB port
  - Restart ADB: $ adb kill-server && adb devices

PROBLEM: "Tag does not support ISO-DEP"
SOLUTION:
  - Card may not be NFC-compatible
  - Try different card
  - Reposition card (usually back of phone)
  - Check NFC enabled in phone settings

PROBLEM: All probes fail even on loaded card
SOLUTION:
  - Card may be damaged or non-standard
  - Try another card
  - Check card is genuine Rav-Kav
  - Clean NFC contact points

PROBLEM: Installation fails
SOLUTION:
  - Uninstall first: adb shell pm uninstall com.unicapitalgroup.ravkavreader
  - Retry install: adb install RavKavCardReader_Enhanced_AUTH-2026-001.apk

PROBLEM: App crashes
SOLUTION:
  - Check logcat: adb logcat | grep RavKavReaderPoC
  - Uninstall and reinstall APK
  - Try different device if available
